## Project Overview

BeeBot is an AI-powered autonomous pollination system designed to explore how computer vision, machine learning, and robotics can support sustainable agriculture.

The project investigates how autonomous systems could identify flowers and assist with pollination, addressing challenges associated with declining pollinator populations and the need for more sustainable agricultural practices.

Developed as part of the Imperial STEMathon India, BeeBot combines AI/ML research with practical robotics design.

## The Problem

Pollinators play a critical role in global food production and ecosystem stability. However, environmental changes and declining pollinator populations create challenges for agricultural sustainability.

BeeBot explores the potential of autonomous robotic systems to assist with pollination by identifying flowers through computer vision and developing a platform capable of navigating agricultural environments.

The project aligns with **UN SDG 13: Climate Action**, exploring how emerging technologies can contribute to more resilient and sustainable agricultural systems.

## AI/ML and Computer Vision

The computer vision component uses **YOLOv8** to detect and identify flowers from images captured using a phone camera.

The system follows this general workflow:

1. **Image Acquisition:** Capture images of flowers using a camera.
2. **Dataset Development:** Build and organize a custom flower-image dataset.
3. **Model Training:** Apply YOLOv8 for object detection and flower recognition.
4. **Detection:** Identify flowers in the input images.
5. **Robotic Integration:** Explore how recognition outputs could guide the robot's interaction with flowers.

This approach demonstrates how object detection can be applied to a real-world agricultural problem.

## Robotics and Autonomous Navigation

Beyond image recognition, BeeBot explores the integration of computer vision with autonomous robotics.

The proposed system considers:

- **LiDAR Integration:** Investigating LiDAR as a potential method for environmental sensing and obstacle detection.
- **Autonomous Navigation:** Exploring how sensor information could support movement through agricultural environments.
- **Pollination Mechanism:** Developing the concept of a robotic mechanism that could interact with flowers to assist with pollination.
- **AI-Robotics Integration:** Connecting flower-recognition outputs with the broader robotic system.

LiDAR integration and further autonomous capabilities represent planned development rather than completed implementation.
